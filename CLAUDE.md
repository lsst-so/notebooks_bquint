- The EFD schema is in https://ts-xml.lsst.io/
  - All the EFD commands are translated as `lsst.sal.[CSC Name].command_[command name]`
  - All the EFD events are translated as `lsst.sal.[CSC Name].logevent_[event name]`
  - All the EFD telemetry is translated as `lsst.sal[CSC Name].[telemetry name]`
