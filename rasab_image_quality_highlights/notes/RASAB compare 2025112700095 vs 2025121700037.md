# Comparison: visit 2025112700095 vs 2025121700037 (RASAB presentation)

Date: 2026-10-20. Q&A between Bruno Quint and Claude Code, saved for the RASAB talk.
Data source: ConsDB `cdb_lsstcam.visit1` + `visit1_quicklook` + `ccdvisit1_quicklook`, USDF
Postgres replica via `rubin_nights.ConsDbSql`.

## Prompt

> Can you compare the visit 2025112700095, which is expected to be the best visit, with
> 2025121700037? 2025112700095 is supposed to have the best image quality.

## Answer

Both are 30 s i-band LSSTCam visits with full focal-plane coverage (188 science detectors), and
they are nearly tied in raw delivered FWHM. 2025112700095 is marginally sharper and has the more
uniform, rounder PSF; 2025121700037 has the better *telescope* performance once the seeing is
accounted for, because it was taken in worse seeing and at lower elevation yet delivered almost
the same FWHM.

| Quantity | 2025112700095 | 2025121700037 |
|---|---|---|
| Night / seq_num | 2025-11-27 / 95 | 2025-12-17 / 37 |
| Image type, program, reason | science, BLOCK-407, `template_blob_i_33.0` (survey) | acq, BLOCK-T539, `infocus_initial_alignment` (AOS test) |
| Observation start (UTC) | 2025-11-28 03:09:38 | 2025-12-18 01:09:24 |
| Field (RA, Dec) | 31.08, -42.29 deg (low-dust survey field) | 42.98, -59.61 deg |
| Altitude / airmass | 74.4 deg / 1.04 | 60.0 deg / 1.15 |
| Azimuth / sky rotation | 216.7 / 310.7 deg | 170.1 / 252.8 deg |
| Wind speed | 9.1 m/s | 3.8 m/s |
| DIMM seeing | 0.67 arcsec | 0.86 arcsec |
| Donut-blur seeing estimate | 0.68 arcsec | 0.64 arcsec |
| AOS residual (optics) FWHM | 0.38 arcsec | 0.48 arcsec |
| **Delivered PSF FWHM, median over detectors** | **0.646 arcsec** | **0.659 arcsec** |
| FWHM across focal plane, min / 5th pct / 95th pct / max | 0.60 / 0.61 / 0.69 / 0.74 arcsec | 0.58 / 0.59 / 0.72 / 0.80 arcsec |
| FWHM corrected to zenith (× airmass^-0.6) | 0.631 arcsec | 0.605 arcsec |
| Delivered / DIMM | 0.97 | 0.77 |
| PSF ellipticity, median / 95th pct | 0.095 / 0.234 | 0.110 / 0.259 |
| Fraction of detectors with ellipticity > 0.2 | 9 % | 19 % |
| Median e1 / e2 | +0.005 / +0.075 | -0.082 / +0.033 |
| Guider mean e1 / e2 | -0.036 / +0.018 | -0.024 / +0.133 |
| Rank by raw FWHM among all 18002 full-frame visits (exp ≥ 15 s), Oct 24 – Dec 31 2025 | 25th | 37th |

Reading of the comparison:

- **Delivered image quality: effectively a tie, slight edge to 2025112700095.** The 0.013 arcsec
  difference in median FWHM is below the detector-to-detector scatter of either visit. The November
  visit is also more uniform across the field (5th to 95th percentile span 0.08 arcsec vs 0.13) and
  rounder (half as many detectors above ellipticity 0.2). It remains the stronger "best image" slide.
- **Telescope contribution: 2025121700037 looks better.** Its DIMM seeing was 0.86 arcsec and it was
  at airmass 1.15, yet it delivered 0.66 arcsec. The delivered FWHM is well below the DIMM value for
  both visits, so the quadrature "system contribution" cannot be computed from DIMM for either. The
  donut-blur estimate (0.64 arcsec) agrees with the delivered FWHM for the December visit, which
  suggests the DIMM was reading high at that moment rather than the telescope beating the seeing.
- **The two visits are different kinds of observation.** 2025112700095 is a survey template visit from
  the main science block. 2025121700037 is an `acq` image from the AOS alignment block BLOCK-T539,
  taken while the active optics loop was being set up (`infocus_initial_alignment`); its AOS
  residual (0.48 arcsec) is correspondingly larger. Every one of the 336 full-frame visits on
  2025-12-17 is of type `acq`; no `science`-type visits were taken that night.

## Why 2025121700037 was not in the earlier "best visit" ranking, and a caveat

The Oct–Dec 2025 ranking in `RASAB best image quality visit Oct-Dec 2025.md` selected
`img_type = 'science'` only. 2025121700037 is `img_type = 'acq'`, so it was excluded, and so were
all other AOS acquisition images. If acquisition images are admitted, several AOS-test visits beat
both of these in raw FWHM, all in i band from BLOCK-T539 `infocus_initial_alignment`:

| Visit | Night | Airmass | DIMM | Delivered FWHM |
|---|---|---|---|---|
| 2025121700028 | 2025-12-17 | 1.15 | 0.58 | 0.585 arcsec |
| 2025121700030 | 2025-12-17 | 1.15 | 0.74 | 0.597 arcsec |
| 2025103000050 | 2025-10-30 | 1.09 | 0.64 | 0.601 arcsec |
| 2025103000047 | 2025-10-30 | 1.09 | 0.69 | 0.614 arcsec |
| 2025121700029 | 2025-12-17 | 1.15 | 0.64 | 0.614 arcsec |

Among all 18002 full-frame visits with exposure ≥ 15 s in the period, 2025112700095 ranks 25th and
2025121700037 ranks 37th on raw FWHM. 2025112700095 is still the best *survey science* visit, which
is the cleanest statement for the talk ("the survey itself delivered 0.65 arcsec"). If the narrative
is instead about the best image the telescope produced at all, 2025121700028 at 0.585 arcsec on
2025-12-17 is the candidate, with the caveat that it is a 30 s acquisition image from an AOS test.

## Method

- Visit metadata and per-visit aggregates from `visit1` joined to `visit1_quicklook`; per-detector
  `psf_sigma`, `psf_ixx/ixy/iyy` from `ccdvisit1_quicklook`, corner wavefront sensors (191, 192,
  195, 196, 199, 200, 203, 204) excluded.
- Delivered FWHM = `psf_sigma` × 2√(2 ln 2) × 0.2 arcsec/pix. Ellipticity e1 = (Ixx − Iyy)/(Ixx + Iyy),
  e2 = 2 Ixy/(Ixx + Iyy), |e| = √(e1² + e2²).
- Zenith correction FWHM × airmass^-0.6 (no wavelength term, both visits are i band).
- Ranking population: `day_obs` 20251024–20251231, `exp_time >= 15 s`, `n_inputs >= 150`, all
  `img_type` values (acq 9239, science 7478, engtest 1231, focus 54).
- Per-detector numbers via `describe_visit()` in `../python/rasab_iq_reports.py`.
